# 🏠 HomeLab 2026

Private home infrastructure project.

## Vision

Create a reliable, secure and self-managed home infrastructure.

Main principles:

- full control over hardware and software;
- data ownership;
- security;
- redundancy;
- documentation of every decision.

---

# 🏗 Architecture Overview

## Network

- MTS + Beeline dual ISP
- NanoPi R5S — main router
- OpenWrt
- Xiaomi BE7000 — Wi-Fi Access Point
- Beeline IPTV through NanoPi R5S

## Server

Main computing node:

- Gaming PC / HomeLab Server

Planned services:

- Docker
- Jellyfin
- Immich
- PostgreSQL
- Grafana
- Prometheus

## Storage

Future:

- NAS
- HGST SAS storage
- Backup system

## Remote Access

- VPS
- AmneziaVPN
